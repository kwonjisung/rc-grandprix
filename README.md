# 미니 RC 그랑프리

방구자동차 감성의 RC카 레이싱 웹게임. 미끄러지는 조작감, 언덕·점프, 방구 부스터, 코스 10개, 디테일 레이싱카 5대(데칼 포함).

- 플레이: `index.html`을 브라우저로 열기 (GitHub Pages로 배포 가능)
- 조작(PC): W 가속 · S 브레이크 · ←→ 조향 · Space 방구 부스터 · Shift 드리프트 · V 차 안 시점 · C 시점 전환 · Esc 일시정지
- 조작(휴대폰): 화면을 누르고 있으면 전진 · ◀▶ 조향 · 뿡! 버튼 부스터

## 구조

| 파일 | 내용 |
|---|---|
| `src/head.html` | 화면 마크업과 스타일 |
| `src/core.js` | 물리(접지력·미끄러짐·경사·점프), 차 충돌, AI, 코스 10개 데이터 |
| `src/render.js` | three.js 3D 렌더러, 시점(운전자 시점 포함), 터널·다리·테마 소품 |
| `src/cars.js` | 레이싱카 5종 모델링(차체 프로파일·휠·윙·데칼) |
| `src/game.js` | 레이스 진행, HUD, 리플레이, 평가, 기록 저장, 사운드 |
| `src/menu2.js` | 디오라마 코스 선택, 차고(차 선택), 버전 정보 |

`src/build.sh`를 실행하면 위 파일들을 합쳐 `index.html`을 다시 만든다.

현재 버전: v2.3
